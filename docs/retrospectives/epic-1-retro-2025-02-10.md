## Challenges and Growth Areas

### 1. Company Context Enforcement Complexity
**Issue:** Company context issues appeared in 3 out of 8 stories (Stories 1.3, 1.4, 1.5)

**Root Cause:** `CompanyScopeEnforcer` requires `CompanyContext` to be set before saving `CompanyScopedEntity` entities, but context wasn't always set early enough in operations.

**Impact:** Multiple fixes needed across stories, some debugging time lost.

**Resolution:** 
- Story 1.3: Set `CompanyContext` before password validation in login
- Story 1.4: Set context during invitation acceptance
- Story 1.5: Set context before user operations

**Lesson Learned:** Company context must be set early in operations (before any entity save). Pattern is sound but needs better documentation.

### 2. Security Issues Caught in Review
**Issue:** Security issues found during review rather than during development (Stories 1.3, 1.5)

**Examples:**
- Story 1.3: Missing `SameSite=Strict` on refresh token cookie (fixed)
- Story 1.5: Role hierarchy needed (added)

**Impact:** Required fixes after story completion, could have been prevented.

**Lesson Learned:** Security checklist needed before marking stories complete.

### 3. Frontend Test Coverage Gaps
**Issue:** Frontend tests missing for Stories 1.5, 1.6

**Impact:** Non-blocking but creates technical debt.

**Lesson Learned:** Frontend tests should be part of Definition of Done (minimum coverage to be defined).

### 4. Pattern Documentation
**Issue:** Company context pattern needed clearer documentation

**Impact:** Developers had to learn through trial and error

**Lesson Learned:** Pattern documentation required for reusable patterns.
